# 方法论 —— 结论是如何做出的

本计划最具复用性的产物不是某个单点结果;而是产出结果的纪律。本文就是那套纪律的书面形态。

## 三级证据

计划中每个结论携带且仅携带三级之一。没有中间态。

| 级 | 定义 | 权限 |
|---|---|---|
| **A1** | 直接运行时观测,判据自证行在本轮在场 | 可独立支撑设计与执行决策 |
| **A2** | 间接推断:排除法、跨文档推理、单源静态推导 | 永不单独支撑设计或发射;引用必须标注 |
| **B** | 未探测:未涉及,或证据链未闭合 | 禁止作为任何行动的依据 |

两条硬规则:

- A2 升 A1 的唯一路径是专门设计的判据轮,直接观测该事物。
- "未探测"不等于"不存在"。盲区必须声明,不得静默当缺席。

## 判据先行

任何节点被行使之前,其观测通道必须先存在并闭环。一轮的成功判据若无法轮内读出,则不是合法轮。通道断裂时,唯一合法的主攻是修通道——对着读不出的判据发射轮次是制造噪声,而把噪声洗成"结果"正是本纪律要防的失败模式。

阶段 0 是该规则的物理表达:[0.2] 与 [0.3] 先于任何内核命题存在,后续每个命题都有能扛过内核死亡的证人。

## 单变量轮

合法测试轮恰好只改一个东西,且该物即本轮裁决对象。多变量轮无归因力——两件事都变了而结果变了,哪件都没学到。

配套:**预注册判决表**。轮前,每个分支结局写死为二值判决加后续动作。结局空间未预注册的轮产不出结论,因为结论会是事后挑选的。

## 节点稳定性

研究命题以显式闭环条件的节点跟踪。节点 STABLE 仅当:

1. 闭环条件在认证轮之前写定;
2. 运行时判据连续至少**三轮**通过;
3. 复现路径文档化到换会话(换人、换日)可重跑;
4. 命题为**机制级**:在更高阶段全部重设计后仍成立,下游不继承烂地基。

静态分析可支撑设计。它永远不能把节点标 STABLE——反汇编展示代码长什么样,不展示它在特定交错下的运行时行为。

## 链合法性规则

测试轮合法仅当其依赖的全部前提已 STABLE。前提未定,则前提的裁决轮先行。这取缔了利用研究中最诱人的失败:"我们看后面阶段的行为来推断前面阶段做了什么"——那是在让未知数翻倍,不是在消解它。

## 强制回写

未回写跟踪文档的轮次不存在——其结果不得被后续任何轮引用。每条记录五字段:试了什么、证据等级、证据在哪、结果是什么、改变了什么。

## 为什么这超出本项目

利用研究以一种特征方式失败:热情把弱信号转成自信叙事,叙事长出依赖,然后一个承重"事实"被证实是未测假设时全楼塌掉。上述纪律是反制:命题出生即分级,判据先于行使,一次一个变量,判决预注册,地基先稳再站人。

严格执行时,它把利用研究从讲故事变成证据系统——这就是"我们相信 walk 消费了几何"与"ret2 = 0,连续十八轮,日志附上"的差别。
